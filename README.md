# Quantum Blur - Interactive Version

This is a Quantum Blur repository for the interactive web application, all built with JavaScript version of MicroMoth. Thanks to the native quantum simulations, there is no need to make `Flask` or `Django` for this simple demo website.

- Micromoth: https://github.com/moth-quantum/MicroMoth
- Micromoth for JavaScript: https://github.com/moth-quantum/MicroMoth/tree/main/versions/JavaScript
